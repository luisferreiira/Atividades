# Atividades de C# — Linguagem e Técnicas de Programação

Repositório com exercícios práticos desenvolvidos durante a disciplina de **Linguagem e Técnicas de Programação**, do curso de **Sistemas de Informação (SI)** — IFSULDEMINAS, Campus Machado.

## 🛠️ Tecnologias

- **Linguagem:** C#
- **Framework:** .NET 10.0
- **IDE:** Visual Studio e Visual Studio Community


## ▶️ Como executar

1. Clone o repositório
2. Abra a pasta do projeto no **Visual Studio Community** ou no **VS Code** (com a extensão C# Dev Kit instalada)
3. No arquivo `.csproj`, altere a tag `<StartupObject>` para o nome da classe da atividade que deseja rodar, por exemplo: `<StartupObject>MediaPositivos</StartupObject>`
4. Execute com `F5` (Visual Studio) ou `dotnet run` (terminal)
